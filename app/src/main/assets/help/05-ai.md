# AI assistant (optional)
The IDE works fully without AI. When you turn it on (Settings → AI assistant) you choose:
- **Anthropic** (online), or
- **OpenAI-compatible** — any service with a `/chat/completions` endpoint over HTTPS, **or a model server running on this phone** at `http://127.0.0.1:<port>/v1` (for example llama.cpp's `llama-server` or Ollama inside Termux). Only loopback may use plain HTTP; such requests never leave the device and are labelled "On this phone".

## What is sent
Only what you choose: your request text and the files or line ranges you add. Before anything is sent:
- likely secrets (API keys, tokens, passwords, private keys, credentials in URLs) are **masked**;
- text that looks like instructions aimed at the AI ("ignore previous instructions…") is flagged and sent as data only;
- the **consent screen** shows provider, address, purpose, file list, size, risks and — via *Review data* — the exact request body. Approve once, or deny. There is no "always allow".

## What comes back
AI answers are treated as untrusted suggestions:
- file changes are shown as **diffs**; you tick the changes you want; a snapshot is taken before anything is written; files that changed meanwhile are refused;
- suggested paths outside the project are rejected;
- shell commands are only displayed with a risk label.

The API key is stored encrypted with the Android Keystore and sent only in the request header. Only metadata of AI sessions is logged (time, provider, sizes, hash) — never the content.
